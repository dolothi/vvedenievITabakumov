# papochka

Flask-приложение: регистрация, вход, чат с ИИ (история чатов, картинки, выбор модели) и две мини-игры — Flappy Sasha и Sasha Run.

Дизайн: спокойный фиолетовый фон, крупный песочный заголовок (шрифт Unbounded), мягкие скругления и тонкие иконки.

## Запуск на новом компьютере

1. Установить [uv](https://docs.astral.sh/uv/getting-started/installation/):
   - Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
   - macOS / Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
2. Скачать проект: `git clone https://github.com/dolothi/vvedenievITabakumov.git`
   (или на GitHub: Code → Download ZIP) и перейти в папку проекта.
3. Создать в папке проекта файл `.env` с ключом Tokenator (в git он не хранится):
   ```
   AI_API_KEY=ваш-ключ
   ```
4. Запустить: `uv run papochka` — uv сам скачает нужный Python и зависимости.
5. Открыть http://localhost:5001 и зарегистрироваться.

Без ключа сайт и игры работают, а чат отвечает, что ИИ не подключён.

## Чат

- Ответ ИИ печатается по мере генерации и форматируется: списки, жирный текст, блоки кода с подсветкой и кнопкой «Копировать» (нужен интернет, без него ответ показывается обычным текстом).
- Под ответом иконки «Копировать» и «Переспросить» (ответ заново — можно сначала выбрать другую модель).
- Чаты: поиск в боковом меню, переименование двойным кликом по названию.
- Горячие клавиши: Ctrl+K (Cmd+K на Mac) — новый чат, Esc — скрыть/показать меню (состояние запоминается).
- Картинки: скрепка в поле ввода, до 3 штук (jpg, png, webp, gif). Перед отправкой они уменьшаются, ИИ их «видит».
- Модель выбирается в списке под полем ввода и запоминается. Если выбранная модель недоступна, чат сам пробует соседние. Список моделей — `MODELS` в `src/papochka/app.py`.
- **Роль ИИ** задаётся в `src/papochka/prompt.txt`: впишите туда любой промт (например, «Ты учитель информатики…»). Файл читается при каждом сообщении — перезапуск не нужен.

### Человечек

Когда поле ввода активно, над ним появляется мультяшный человечек: перчатки возникают «из воздуха», он выглядывает, оглядывается по сторонам, а потом следит глазами за курсором. Если кликнуть по нему — получит щелбан: улетит вниз и вылезет снова. Уходит, когда курсор покидает поле.

## Настройки (.env, необязательные)

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `DB_BACKEND` | `sqlite` — локальная база в файле, `mysql` — школьная база | `sqlite` |
| `FLASK_DEBUG` | `1` — сервер сам перезапускается при правках кода | выкл |
| `PORT` | порт сайта | `5001` |

После правки `.env` сервер нужно перезапустить (Ctrl+C и снова `uv run papochka`).

## Структура

- `src/papochka/app.py` — маршруты, база данных, запросы к ИИ
- `src/papochka/prompt.txt` — промт (роль) ИИ
- `src/papochka/templates/` — страницы: вход, регистрация, чат (с человечком), выбор игры и `game.html` — общий для обеих игр
- `src/papochka/static/theme.css` — общий стиль всех страниц, `dashboard.css` / `dashboard.js` — чат
- `src/papochka/static/game.js`, `dino.js` — игры, `game-common.js` — их общий код, `faces.png` — все спрайты головы в одной картинке
- `src/instance/` — локальная база и загруженные картинки (в git не попадает)
